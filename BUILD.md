# Build the APK

## Option A: Android Studio (easiest)
1. Install Android Studio, then File > Open > this folder
2. Wait for Gradle sync
3. Build > Build Bundle(s)/APK(s) > Build APK(s)
4. APK: app/build/outputs/apk/debug/app-debug.apk

## Option B: GitHub (no install)
1. Create a GitHub repo and upload this folder's contents
2. Open the Actions tab > "Build APK" > run it
3. Download "SynapseGaming-apk" from the finished run

Install: copy app-debug.apk to your phone, open it, allow "install unknown apps".
